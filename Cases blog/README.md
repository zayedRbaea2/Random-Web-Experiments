## Overview
A simple web application designed to track status during a session.  
The app allows you to:
- Add employee names with their current status ("تم" / "لم يتم").
- Modify statuses on the fly.
- Copy any employee name with a single click.
- Save all current session data to a `.txt` file named with the current date.

## Features
- **Live Clock**: Displays the current time at the top of the page.
- **Two Separate Sections**: Organize employees into two groups.
- **Data Export**: Save session data in a structured `.txt` format for future reference.

## How It Works
1. Enter a name and select the status.
2. Add the employee to one of the two sections (I / II).
3. Click **Save Data** to download a `.txt` file containing all current records.
